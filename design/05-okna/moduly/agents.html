O tym opracowaniu — moduł Agents (fabryka ekspertów) na warstwie stanowiska

Jakie okno przedstawia

  • Moduł Agents środowiska WorkSpace/CodeStudio/TalkIn przebudowany na warstwę stanowiska (kontrakt systemu projektowego).
  • Okno wiodące = Agent Builder (kanwa): widok Biblioteka ekspertów + widok Edytor z formularzem Tożsamości (Załącznik A) i klikalnym cyklem tworzenia eksperta (7 komponentów).
  • Pozostałe okna operacyjne jako dokowane panele: Model Configuration, Skills Manager, Connectors Manager, Permissions Center (zawsze pełny dostęp — opcja, nie brama). Chat Window jako lewa strefa czatu z pełnym obszarem polecenia.

Odwzorowane interakcje

  • Tryby Talk/Work/Code; hamburger, menu konta (support@danaco-core.pl), ⋮ Panele (pokaż/ukryj każdy panel), filtr szyny.
  • Agent Builder: przełączanie Biblioteka/Edytor, zakładki definicji, klikalny cykl 7 kroków, karty ekspertów → Edytor, podsumowanie definicji skaczące do paneli.
  • Model Configuration: wybór modelu, kanał (API/CLI/SSH/HTTP z opisem), maskowanie klucza, Testuj połączenie. Skills/Connectors: przełączniki przypisania. Permissions Center: grupy zakresu, tabela odczyt/zapis/akcja, macierz izolacji 8, Subagent Network, Resetuj do pełnego dostępu, polityka efektywna.
  • Obszar polecenia: tryb uprawnień „Z pominięciem zgód”, „+”, mikrofon, model, wysiłek, nagrywanie, ↑ Do kolejki.
