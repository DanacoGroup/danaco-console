O tym oknie — Moduł Apps (Danaco Console)

Co przedstawia

  • Pełne stanowisko modułu Apps w warstwie stanowiska v2.1 (monochrom + kropka sygnału).
  • Okno wiodące: Product Builder (tracker etapów, panel kondycji, kafle nawigacji, kamienie milowe, wykonawcy, dziennik wydań).
  • Dokowane panele: Architecture Designer (diagram SVG komponentów + walidacja), Frontend Workspace (podgląd responsywny + build), Backend Workspace (punkty końcowe API + konstruktor zapytań), Deployment Panel (środowisko, historia wdrożeń, strategia).
  • Chat Window z pełnym obszarem polecenia: pasek kontekstu (Ten komputer · projekt · repo · worktree · diff · Zatwierdź zmiany) i wiersz sterowania (tryb uprawnień „Z pominięciem zgód”, „+”, mikrofon, model Fable 5, wysiłek Ultra, nagrywanie, ↑ Do kolejki).
  • Panele uniwersalne (ukryte, w menu „⋮”): Plan, Zadania w tle, Terminal, Pliki.

Do wypróbowania

  • Tryby Work/Code, hamburger, menu konta, „⋮ → Panele” (pokaż/ukryj), filtr szyny.
  • Kafle Product Buildera przewijają do właściwego okna; tracker etapów, przełącznik podglądu responsywnego we Frontend Workspace.
  • Chipy obszaru polecenia (tryb uprawnień, „+”, model, wysiłek), konfiguracja per okno (koło zębate), zamknięcie panelu „×” i przywrócenie z paska kart.
