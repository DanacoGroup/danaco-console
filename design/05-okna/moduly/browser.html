O tym oknie — moduł Browser (stanowisko v2.1)

Odwzorowane okna operacyjne

  • Browser Window (wiodące) — okno robocze = Przeglądarka: pasek adresu z nawigacją i zakładką, karty przeglądania, wspólny podgląd strony z wskaźnikiem obecności AI, pasek pływający zaznaczenia (Wyjaśnij / Wyodrębnij / Notatka), stopka (Podziel ekran · Zrzut · Wyodrębnij dane · Tłumacz). W belce: tryb urządzenia (18), Serwery (19), ołówek/adnotacje (21), ⋮ (17) z trybem czytnika i widokiem podzielonym.
  • Sources Panel — automatyczna lista źródeł sesji, oznaczenie kluczowe, podgląd migawki, eksport, „→ Wyślij do Research”.
  • Notes Panel — notatki powiązane ze źródłem, klasyfikacja (wniosek / cytat / pytanie otwarte), przypięcie, przełącznik Wg źródła / Chronologia.
  • Chat Window — okno komunikacji z pełnym obszarem polecenia (tryb uprawnień „Z pominięciem zgód”, „+” z konektorami i wtyczkami, mikrofon, model, wysiłek, nagrywanie, ↑ Do kolejki).

Tryby i powłoka

  • Tryby właściwe modułowi: Talk / Work (aktywny Work). Panele sterowane menu „⋮ → Panele”.
  • Panele uniwersalne dołączone: Artefakty, Zadania w tle, Pliki (domyślnie ukryte).
