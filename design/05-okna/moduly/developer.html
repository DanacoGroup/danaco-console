O tym oknie — moduł Developer (rollout v2, stanowisko Code)

Okna operacyjne modułu odwzorowane na stanowisko

  • Code Editor — okno WIODĄCE (kanwa edytora, karty otwartych plików, składnia .pt-skl-*, linia stanu).
  • Project Tree — dokowany panel: drzewo repozytorium ze znacznikami zmian (M).
  • Git Panel — dokowany panel: lista zmian, różnicowanie .pt-wiersz-dodany/usuniety, opis commitu generowany przez AI.
  • Build Output — dokowany panel: konsola .pt-konsola z wynikiem pytest.
  • Chat Window — strefa czatów z pełnym obszarem polecenia (tryb uprawnień, „+”, mikrofon, model, wysiłek, ↑ Do kolejki).

Zgodność z aneksem v2.1

  • Tryb właściwy modułu: Code (podświetlony). Środowisko: CodeStudio > Developer.
  • Panele uniwersalne: Plan, Zadania w tle, Terminal, Kolejka, Subagenci, Artefakty — sterowane menu „⋮ → Panele”.
  • Tryb uprawnień domyślny „Z pominięciem zgód”; modele Fable 5 / Opus 5 / Sonnet 5 / Haiku 4.5.
