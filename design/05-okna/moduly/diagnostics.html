O tym oknie — moduł Diagnostics (rollout v2, stanowisko Code)

Okna operacyjne modułu odwzorowane na stanowisko

  • Diagnostics Center — okno WIODĄCE: karty KPI, obraz stanu systemu, korelacja czasowa.
  • Logs Viewer — dokowany panel z filtrem poziomu (Wszystkie/ERROR/WARN/INFO).
  • Errors Panel — dokowany panel: grupowanie błędów po odcisku z licznikiem wystąpień.
  • Recommendations Panel — dokowany panel do przeglądu Operatora; rekomendacja otwiera Code Editor modułu Developer.
  • Chat Window — strefa czatów z pełnym obszarem polecenia.

Zgodność z aneksem v2.1

  • Tryb właściwy modułu: Code (podświetlony). Środowisko: CodeStudio > Diagnostics.
  • Domyślnie poprawki otwierają się do przeglądu Operatora (Recommendations Panel) — zgodnie z zasadą nadrzędną modułu.
  • Panele uniwersalne: Plan, Zadania w tle, Terminal, Kolejka, Subagenci, Artefakty — menu „⋮ → Panele”.
  • Tryb uprawnień domyślny „Z pominięciem zgód”; modele Fable 5 / Opus 5 / Sonnet 5 / Haiku 4.5.
