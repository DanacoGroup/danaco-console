O tym oknie — Moduł Terminal (Danaco Console)

Co przedstawia

  • Pełne stanowisko modułu Terminal w warstwie stanowiska v2.1 (monochrom + kropka sygnału), tryb Code.
  • Okno wiodące: Terminal Tabs — pasek kart powłok (PowerShell · Bash · CMD · Python · SSH), pasek stanu (breadcrumb ścieżki, gałąź Git, profil), działający wpis poleceń w .pt-konsola, pasek narzędzi (split poziomy/pionowy, A–/A+, schemat) oraz szuflada ściągi z 20 poleceniami (Ctrl+/).
  • Dokowane panele: Output Console (widok zagregowany, grep, poziomy, pasek akcji linii błędu, przełączniki prezentacji) i Process Monitor (wiersze procesów Operator/AI, mini-wykresy, „Zakończ” / „Uruchom ponownie”, kanał na żywo).
  • Chat Window z pełnym obszarem polecenia: pasek kontekstu i wiersz sterowania (tryb uprawnień „Z pominięciem zgód”, „+”, mikrofon, model Sonnet 5, wysiłek, nagrywanie, ↑ Do kolejki) oraz blok „Wstaw do terminala / Uruchom teraz”.
  • Panele uniwersalne (ukryte, w menu „⋮”): Plan, Pliki.

Do wypróbowania

  • Wpis polecenia w Terminal Tabs (Enter dopisuje wynik), przełączanie kart powłok (znak zachęty się zmienia), A–/A+ skaluje czcionkę konsoli.
  • Szuflada ściągi „☰” wstawia polecenie do wiersza; menu „⋮ → Panele”, filtr szyny, tryby Talk/Work/Code.
  • Chipy obszaru polecenia, konfiguracja per okno (koło zębate, w tym punkty izolacji technicznej), zamknięcie panelu „×” i przywrócenie z paska kart.
