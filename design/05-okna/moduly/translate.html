O tym oknie — moduł Translate (stanowisko v2)

Odwzorowane okna operacyjne (KANON 7.5)

  • Source Panel — tekst źródłowy z segmentacją, selektorem języka, licznikiem, import/segmentacja; segment aktywny i „wymaga rewizji”.
  • Translation Panels — okno wiodące: siatka równoległa EN/DE/FR obok siebie, ton per panel, status ułamkowy, podpowiedzi TM, kontrola jakości, tłumaczenie zwrotne, eksport.
  • Glossary Manager — słownik terminów z parami językowymi, wykrywaniem niespójności, „nie tłumacz”, ujednolicaniem, import/eksport TBX/CSV.
  • Chat Window — okno komunikacji z pełnym obszarem polecenia (Talk → „Wyślij”).
  • Panele uniwersalne: Pliki, Plan.

Zgodność z aneksem v2.1

  • Powłoka `.sta-powloka`, tryb wyłącznie Talk (aktywny), okruszki TalkIn ▸ Translate, konto support@danaco-core.pl.
  • Obszar polecenia: „Z pominięciem zgód”, „+” z konektorami/wtyczkami, mikrofon, model Sonnet 5, suwak Ultra, nagrywanie, przycisk „Wyślij”.
  • Okno wiodące = Source Panel + trzy Translation Panels obok siebie. Widoczność paneli z menu „⋮ → Panele”. Kropka `.pt-tetno` = praca w tle.
