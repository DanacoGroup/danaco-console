Odwzorowane okna operacyjne

  • Project Dashboard (wiodące) — okno robocze: nagłówek projektu z plakietką statusu, kafle nawigacyjne z licznikami, lista/tablica zadań z paskiem postępu, oś czasu aktywności, operacje na projekcie.
  • Chat Window — okno komunikacji z pełnym obszarem polecenia; wzmianki @plik/@pamięć/@agent, wybór wykonawcy, propozycje pamięci AI.
  • Instructions Panel — edytor instrukcji, szablony, wersje, test w Chat, warstwa projekt/sesja.
  • Context Memory — lista wpisów, zajętość, wpis przypięty, propozycja AI.
  • Project Library — eksplorator plików (siatka/lista), tagi, wersjonowanie, odbiór artefaktów AI.
  • Agent Manager — przypisani agenci, domyślny wykonawca, uprawnienia, nowy agent.
  • Uniwersalne (menu „⋮ → Panele”): Zadania w tle, Terminal.

Zgodność z KANON r.15

  • Powłoka `.sta-powloka`, pasek z hamburgerem, tryby Talk/Work/Code (domyślnie Work), okruszki, szukajka, konto support@danaco-core.pl.
  • Obszar polecenia: tryb uprawnień „Z pominięciem zgód”, „+” z konektorami/wtyczkami, mikrofon, model Fable 5/Opus 5/Sonnet 5/Haiku 4.5, suwak wysiłku Ultra, nagrywanie, ↑ Do kolejki (Work).
