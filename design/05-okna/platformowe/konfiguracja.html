Strategia przydziału
O tym oknie — Konfiguracja na warstwie stanowiska (Danaco Console, ANEKS v2.1 r.15)

Co zbudowano

  • Powłoka stanowiska w tle: pasek (hamburger, Talk/Work/Code, okruszki, szukajka, konto support@danaco-core.pl), pas kart sesji, szyna z filtrem i grupami, okno komunikacji z pełnym obszarem polecenia (tryb „Z pominięciem zgód", „+" konektory/wtyczki, mikrofon, model Fable 5/Opus 5/Sonnet 5/Haiku 4.5, suwak wysiłku Ultra, ↑ Do kolejki).
  • Nakładka modalna okna Konfiguracji nad powłoką — trójkolumnowa: 13 zakresów (nazwy z r.1.2), obszar „Nakładka i wywołanie modelu" oraz Panel prowenancji.
  • Trzy warstwy nakładki: Konstytucja (edytor), Profil/Rola (podgląd + skrót do Agent Builder), Ekspertyza zadaniowa (podgląd + przełącznik budowy dynamicznej Coordinatora).
  • Pola wywołania: System prompt (podgląd wynikowy), Harness, Hooki, Narzędzia dozwolone, Model, Effort, Kanał (Code CLI / Agent SDK / API), Rotacja kont.
  • Panel prowenancji — cztery bloki (argv, system prompt, settings, hash konstytucji), oznaczony jako element ponad źródła L6.
  • Modal „Pula kont Code CLI" ze stanami kont i strategią przydziału.
